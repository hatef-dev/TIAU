# University of Islamic Art of Tabriz Virtual Tour

This project is a virtual tour website for the University of Islamic Art of Tabriz, showcasing the university's facilities, museum, international museum, and store.

## Project Description

The website serves as a virtual tour platform that allows users to explore different sections of the University of Islamic Art of Tabriz through interactive tours. The site is built with HTML, CSS, and JavaScript, featuring:

- A main landing page with information about the university
- Multiple virtual tour sections:
  - University facilities tour
  - International museum tour  
  - University museum tour
  - University store tour
- Responsive design for various screen sizes
- Interactive elements for navigation

## Features

- **Multilingual Support**: Content primarily in Persian/Farsi
- **Interactive Tours**: Click-to-navigate virtual tour experiences
- **Responsive Layout**: Adapts to different device screens
- **Modern Web Technologies**: Uses HTML5, CSS3, and JavaScript
- **Icon Integration**: Includes Ionicons and Font Awesome for enhanced UI
- **Clean Design**: Organized layout with clear navigation

## How to Use

1. Clone or download this repository
2. Open `index.html` in a web browser
3. Navigate through the different sections using the provided buttons
4. Click on tour buttons to explore each virtual tour section
